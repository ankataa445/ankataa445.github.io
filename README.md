# An Ka Taa — Fiche de renseignement & de contact

Formulaire en ligne (page unique) pour l'association **An Ka Taa**.
Les réponses sont envoyées par e-mail via [Web3Forms](https://web3forms.com).

## Configuration (1 seule chose à faire)

Ouvrir `index.html` et coller la clé Web3Forms en haut du fichier :

```js
const WEB3FORMS_ACCESS_KEY = "COLLE-ICI-TA-CLE-WEB3FORMS";
const EMAIL_DESTINATAIRE   = "ankataa.contact@gmail.com";
```

La clé se crée gratuitement sur https://web3forms.com en entrant
`ankataa.contact@gmail.com`. La clé arrive dans cette boîte mail, et
c'est cette adresse qui recevra toutes les fiches remplies.

## Hébergement

Site statique : `index.html` + `logo.png`. Publiable tel quel sur
GitHub Pages, Netlify, Cloudflare Pages, etc.
